Test 1: Fleet Layout at 2 and 4 Boats

Test Objective: Verify that My Fleet displays correctly with a 2-boat fleet (one card per row) and a 4-boat fleet (two columns), at full width, as the browser window narrows, and in a phone simulator - including that reserved boats cannot be removed.

Developer: Robert Breutzmann | Tested On: <date>
Peer Tester: Sara White | Tested On: <date>
Before running Tests 1-3
The database must be at version 1.9.0 (run databasescripts/MoffatBayMarinaDB_V1-9-0_update.sql after the 1.8.0 build; check with currentVersion.sql). That update gives two customers the fleets these tests need:
• Desmond Okafor (desmond.okafor@example.com / MoffatOkafor02!) - 2 boats: Second Wind (reserved, MB-00002) and Harbor Light (not reserved).
• Arthur Penhale (arthur.penhale@example.com / MoffatPenhale05!) - 4 boats: Little Bear (reserved, MB-00005), Wandering Albatross (reserved, MB-00006, no HIN), Kestrel (not reserved), and Morning Tide (not reserved; Type, Registration, Beam and Year left blank).
Run the tests in order: Test 2 changes Wandering Albatross and Kestrel, so Test 1 should see them first. To run Test 2 again, use the reset query under Test 2.

Test 2: Edit a Boat

Test Objective: Verify that the Edit popup fills in the boat's current details, locks the fields that can't change (Length always, HIN once set), lets the customer add a missing HIN once, and shows an accurate old → new confirmation before saving and a summary after saving.

Developer: Robert Breutzmann | Tested On: <date>
Peer Tester: Sara White | Tested On: <date>
StepActionExpected ResultsDev
Test		Peer
Test
1 Log in as arthur.penhale@example.com / MoffatPenhale05! and open My Fleet. Click Edit on Wandering Albatross. A popup titled Edit Wandering Albatross opens, with every field filled in to match the card. Boat Length is greyed out and can't be clicked into, with a note explaining that length sets the slip size and rate. HIN is empty but editable, with a Set once marker and a note that it can't be changed once saved. The clear button reads Revert Changes. Save Changes is disabled, with Nothing changed yet. beneath it. <Pass/Fail> <Pass/Fail>

Edit Wandering Albatross - Length locked, HIN marked Set once
2 Type WAB36C1968AL into the HIN field, then click Save Changes. No error appears under the HIN field, and Save Changes becomes clickable once the HIN is typed. Clicking it replaces the form with the confirmation Save these changes?, listing exactly one row: HIN: empty → WAB36C1968AL, and reading Nothing has been sent yet. Only this field will be saved — everything else on Wandering Albatross stays as it is. Buttons: Go back and Yes, save. <Pass/Fail> <Pass/Fail>

Confirmation popup for adding the HIN
3 Click Go back and check the HIN field, then click Save Changes again and click Yes, save. Go back returns to the form with WAB36C1968AL still in the HIN field (nothing was undone or sent), and Save Changes brings the same one-row confirmation back. After Yes, save, the popup closes and My Fleet reloads. A Saved. Here's what changed: panel appears above the cards, listing HIN: empty → WAB36C1968AL. Wandering Albatross's HIN badge now shows WAB36C1968AL, filled in rather than dashed. <Pass/Fail> <Pass/Fail>

Change summary after adding the HIN, and the updated card
4 Click the × on the summary panel. Then click Edit on Wandering Albatross again, look at the HIN field, and click Cancel. The summary panel closes. In the Edit popup, HIN now shows WAB36C1968AL, greyed out and not editable, with a note that a hull number doesn't change; the Set once marker is gone. Cancel closes the popup with nothing saved. <Pass/Fail> <Pass/Fail>

Wandering Albatross HIN now locked
5 Click Edit on Kestrel. Popup titled Edit Kestrel, filled in to match the card. Boat Length and HIN are both greyed out and not editable (Kestrel already has a HIN). Boat Name, Registration Number, Boat Type, Boat Beam and Year are editable. Save Changes is disabled. <Pass/Fail> <Pass/Fail>

Edit Kestrel - Length and HIN both locked
6 Change Boat Type to Center Console and Year to 2020. Then click Revert Changes. After typing, the hint reads 2 fields will be saved. Revert Changes puts Boat Type back to Powerboat and Year back to 2019 (it does not blank the form), and Save Changes is disabled again with Nothing changed yet. <Pass/Fail> <Pass/Fail>

Kestrel after Revert Changes
7 Change Boat Type to Center Console and Year to 2020 again, then click Save Changes. Confirmation lists exactly two rows: Boat type: Powerboat → Center Console, and Boat year: 2019 → 2020. It reads Only these 2 fields will be saved — everything else on Kestrel stays as it is. No other fields are listed. <Pass/Fail> <Pass/Fail>

Confirmation popup for the Kestrel edit
8 Click Yes, save. My Fleet reloads with the Saved. Here's what changed: panel listing the same two rows. Kestrel's card shows Type Center Console and Year 2020; every other badge is unchanged. <Pass/Fail> <Pass/Fail>

Change summary after the Kestrel edit, and the updated card
