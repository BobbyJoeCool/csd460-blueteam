Comments

Developer (Robert)
This test revealed that when the update on edit a boat fails, all the fields that weren't changed are emptied. Also, the error message persists back to the My Fleet Page.

Fixed after testing (Sep 24, 2026): (1) An edit only sends the fields that changed, so when it failed the server sent the popup back with every other field blank, and the page then copied those blanks over the boat's real values. The server now says which fields were sent, and only those are refilled from what was typed; the rest keep the boat's values. (2) The "Please fix the highlighted boat fields" message was shown on the page above the cards, so it stayed after the popup closed. It now shows inside the popup. The address bar also goes back to /myFleet, so a refresh doesn't offer to resubmit. Step 9's expected result is updated to match; Sara's peer run will be the first check of the new behaviour.
